# Mellow Studio

A playful, pastel creative agency website built with React + Vite.

## Run locally

```bash
git clone https://github.com/yasal01/mellow-studio.git
cd mellow-studio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start local development server |
| `npm run build` | Create production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run oxlint |

## Requirements

- Node.js 18+ (recommended)
- npm

## Sections

Navbar, Hero, Services, Selected Work, About, Creative Process, Contact, and Footer — responsive, with smooth scrolling, hover interactions, and reduced-motion support.
