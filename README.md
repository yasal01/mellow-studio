# Mellow Studio

A playful, pastel creative agency website built with React + Vite.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run oxlint

## Sections

Navbar, Hero, Services, Selected Work, About, Creative Process, Contact, and Footer — all responsive, with smooth scrolling, hover interactions, and reduced-motion support.
